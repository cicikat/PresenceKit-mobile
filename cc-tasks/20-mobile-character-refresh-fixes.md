# 手机端角色切换 / 热力图 / 生活记录 / 自动刷新（2026-09-14）

范围：仅修改 Emerald-mobile；后端与桌面只读核查，不改契约、不对外发布。
每项实现并验证后勾选；真机未验证项明确保留。

依赖：1 与 4 都动聊天历史，先做 1 再做 4。2、3 可与 1 并行，本轮仍顺序推进以免断连。

- [x] 1. 切换角色后头像、名字、历史立即跟上，不必重启。
  - 启动即读取 prompt-assets，聊天顶栏用当前角色名，而不是等打开设置。
  - 本机备注名和头像按角色 id 分槽；切走后加载该角色自己的，没有则用后端名和字母头像。
  - PATCH 成功后清空并重读该角色的聊天历史、日记、花园、资料快照；日历页随角色 id 重载。
- [x] 2. 热力图除今日外的格子要能显示已有聊天，而不是一片空。
  - 连续天数请求失败时保留当月数据，不能整页空白。
  - 刷新时保留上一份日历，避免闪成空图。
  - 嵌套滚动里用明确行列画格子，避免 GridView 被裁成只剩今日。
  - 未知日和零活动日外观分开；有回填轮数的日子正常上色。
- [x] 3. 生活记录查看/校正去掉废话和内网地址。
  - 表单标签去掉括号说明；列表卡不展示识别长文。
  - 校正窗不展示原始识别墙、同意说明、节点/origin。
  - 队列弹窗只保留状态、待同步数、最近成功时间，不 dump JSON/URL。
- [x] 4. 自动刷新保持当前顺序和图片，不整页跳动。
  - 后台对账静默：不打「加载历史」、不 animate 滚到底。
  - 本地图片气泡对账后仍保留原图附件，不用识别/OCR 正文替换。
  - 对账以服务端顺序为底，失败/发送中/未匹配图片插在原位置，不把已有气泡打乱。
  - 内容未变则不 notify；人在底部才 jump，人在上面保持偏移。

# 工单 01：Token/后端/中继对话框触发 `_dependents.isEmpty` 断言 → 全局错误页

**可与工单 02 并行；与工单 03 无依赖。**

## 现象

在「系统设置 → 访问 Token / 后端节点 / 推送中继」任一对话框里填写并保存（对错都一样），
整屏被 `AppErrorFallback`（"页面出了点问题"）替换，错误文本为：

```
'package:flutter/src/widgets/framework.dart': Failed assertion: line 6161 pos 14:
'_dependents.isEmpty': is not true.
```

## 背景

- `lib/main.dart:49` 设置了 `ErrorWidget.builder = AppErrorFallback`，所以任何 build 期异常都会整屏替换。
- 该断言是 **debug-only**（release 下 assert 被剥离，不会红屏，但根因仍在）。日常安装包目前是 debug 构建（见工单 02）。
- 三个对话框共同模式（`lib/pages/app_shell.dart`）：
  - `_openAdminTokenSettings()`（约 L384–511）
  - `_openBackendSettings()`（约 L986–1073）
  - `_openRelaySettings()`（约 L1075–1191）

## 根因假设（按嫌疑排序，先复现拿全 stack 再定）

1. **保存/取消时带焦点直接 pop**：TextField `autofocus: true`，IME 和文本选择 overlay（handles/toolbar/magnifier，挂在 root Overlay）还依赖 route 内的 InheritedElement（token 对话框里还额外包了一层局部 `Theme`，L391–427），同帧 `Navigator.pop(dialogContext)` 甚至紧接 `popUntil(isFirst)`（L498–500）卸载 InheritedElement 时依赖者还活着 → 断言。
2. **controller 过早 dispose**：token 对话框在 `await showDialog` 返回后立即 `controller.dispose()`（L492）；backend/relay 用 `whenComplete` dispose。两者都在**退出动画尚未播完**时执行，TextField 还挂在树上。
3. token 对话框内的局部 `Theme(data: ...copyWith(textSelectionTheme...))` 放在 route builder 里，是 overlay 依赖它的直接来源。

## 修复要求

1. 先 `flutter run` 复现，把完整 stack trace 贴进本工单（确认是哪个 InheritedElement）。
2. 所有对话框按钮里，**pop 之前先收焦点**：`FocusManager.instance.primaryFocus?.unfocus();`。
3. `_openAdminTokenSettings` 里保存成功后的 `popUntil(isFirst)` 不要与 dialog pop 同帧，
   放到 `WidgetsBinding.instance.addPostFrameCallback` 或现有的 320ms 延迟回调里一起做。
4. controller 延迟释放：等退出动画结束后再 dispose（post-frame + ~300ms，或
   `route.completed.then(...)`）。三个对话框统一处理，建议抽一个
   `showTextInputDialog` 辅助函数收敛这套样板。
5. 把 token 对话框的局部 `Theme` 包装移除，改为在 `MyApp` 的 `ThemeData` 里配
   `dialogTheme` / `inputDecorationTheme` / `textSelectionTheme`（注意自定义色盘 c 是运行时
   状态，如必须局部覆盖，至少确保它不随 dialog route 一起被卸载时仍有依赖者——收焦点后再 pop 已可规避）。

## 验收

- debug 构建下，对三个对话框各做 20 次：填写→保存、填写→取消、聚焦后直接返回键，均不出现错误页、logcat 无该断言。
- `flutter analyze` 通过；相关现有测试不回归（`flutter test`）。

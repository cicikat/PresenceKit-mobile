## 2. 🟡 中继器状态显示与通知链路修复

先厘清再修,现象三件套:

- **状态矛盾**:左侧在「连接中/已停止」间跳,右侧恒为「未开启」——两个指示
  读的不是同一状态源。排查:左右两个 UI 各自绑定的状态变量/流,统一为单一
  状态机(未配置 / 连接中 / 已连接 / 已停止 / 错误),两处显示同源;
  「连接中」抖动若来自 ntfy 长连接重连,加去抖(N 秒内不回落显示)。
- **无横幅通知(heads-up)**:锁屏通知有但横幅从不出现,典型原因是
  notification channel 建立时 importance 低于 HIGH——channel importance
  创建后不可改,修复需**换新 channel id** 重建(旧 channel 用户侧可能已
  存在),并确认 Android 13+ 的 POST_NOTIFICATIONS 运行时权限申请流程存在。
- **悬浮窗从不触发**:核查 SYSTEM_ALERT_WINDOW(overlay)权限申请引导是否
  真的走到系统设置页、开关状态是否持久化、触发条件代码路径是否可达
  (打日志实测一条消息全链路)。若权限被拒,设置页开关旁要显示「未授权」
  而不是装作已开启。
- 验收用真机:后端 push 一条测试消息 → 横幅弹出、锁屏可见、悬浮窗出现,
  三者齐活;权限拒绝场景各有明确提示。

## 3. 🟡 Chat 世界书/破限显示对齐 desktop

- 现象:mobile 显示英文 id,desktop 显示中文自定义标签;且 desktop 勾了
  4 条、mobile 只见 3 条——怀疑读的不是同一数据源。
- 排查:desktop 走的是后端 `/lorebook` 与 `/jailbreak-entries`(全量 CRUD,
  条目含标签字段);查 `lib/services/backend_client.dart` 里 mobile 实际调的
  端点与解析的字段。逐项回答:①端点是否相同;②少的那 1 条差在哪
  (过滤条件?分页?不同端点?);③显示字段为何取了 id。
- 修复:与 desktop 同端点、同字段(显示自定义标签,无标签才回落 id);
  条目数量与勾选状态和 desktop 完全一致;`lib/models/app_models.dart`
  模型字段补齐。

## 4. 🟡 聊天气泡长按菜单(复制/全选/回复)

- 长按任意气泡弹菜单:**复制**(整段文本进剪贴板)、**全选**(进入文本
  选择模式自由选取,Flutter `SelectionArea`/`SelectableText` 按现有气泡
  实现选型)、**回复**(仅角色气泡显示)。
- 回复:选中后输入框上方显示引用预览条(可取消),发送时按后端 Brief 98 §2
  契约携带 `reply_to: {text(截断200字), ts}`;后端未升级(字段被忽略)时
  行为退化为普通消息,不报错。
- 分段气泡:回复目标是**单个气泡**(一段),不是整条回复,引用文本取该
  气泡自身内容。

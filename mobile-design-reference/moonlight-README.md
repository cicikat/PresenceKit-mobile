# 冷白月光 · UI 光玻璃

直接双击 g-moonlight.html，Chrome / Edge / Safari 离线打开，无需安装或服务。

## 视觉层次（当前版本）

1. 底层：覆盖整个手机屏幕的连续雾紫、冷蓝、珍珠白与局部粉金光流。光带横向游走、曲线缓慢变化，没有背景装饰气泡或玻璃实体。
2. 普通 UI：聊天框、导航、输入栏、按钮、状态卡就是玻璃气泡本身。WebGL 按这些 DOM 的实际位置和圆角计算透镜边缘采样，CSS 叠加轻度真实模糊、透明度和细亮边。普通栏目只透过、轻微折射同一底层光流。
3. 稀有事件：仅一个手动预览的「梦境交汇」框，特殊光学层产生反色与彩虹响应。色谱由同一个底层光流的位置与强度驱动，不是额外循环的彩虹贴图。文字单独保持亮色，不受反色影响。

右侧或手机右上：纯背景预览隐藏全部 UI 及对应折射；暂停流动冻结光带；预览稀有事件/收起稀有事件切换唯一的特殊框。稀有事件默认关闭，没有随机触发、后端触发或真实业务。输入和发送只是视觉反馈，不联网、不存储。

24 秒周期，最多 24 帧/秒，绘制宽度上限 420 像素。系统减少动态、手动暂停和页面隐藏停止 RAF。WebGL 不可用时显示静态光带渐变降级，无背景气泡。

## 限制与证据

二维屏幕空间透镜/光场近似，不是 Apple 原生 Liquid Glass，没有真实多次折射、完整物理光线追踪或焦散。参考材质原则：https://developer.apple.com/videos/play/wwdc2025/219/

2026-10-10，Chrome headless / SwiftShader 实际离线渲染。preview、background、desktop、mobile、focus、event 六张截图；validation.json 记录零页面错误、零外部请求，320/360/390/430 无横向溢出，reduce 下 canvas 像素不变、恢复动画后变化，以及稀有卡片光谱随流动变化。已目视检查普通、纯背景与特殊事件构图。

真机 GPU 性能、软键盘、Safari not-run。不修改 Flutter、Android、后端或其他样机。无跨端影响。

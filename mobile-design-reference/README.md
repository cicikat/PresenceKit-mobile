# 手机端视觉方向参考

入口为 `index.html`，可双击打开四套并排对比，点击「单独体验」打开完整手机页面。无需安装依赖或联网。每套包含聊天、日记、花园、设置与梦境预览；输入消息只在当前页面模拟显示，刷新恢复，不发请求、不保存。

| 方向 | 入口 | 设计取向 | 取舍 |
|---|---|---|---|
| A 书信阅读 | a-paper.html | 顶部分栏导航、日期刊号、大标题、连续信件正文、底部回信框 | 温柔耐读；视觉张力较弱 |
| B 专注聊天 | b-sage.html | 左上菜单隐藏导航、紧凑联系人栏、时间线聊天、内嵌花园卡片 | 适合日常高频聊天，优先推荐作为基础 |
| C 月夜剧场 | c-night.html | 全屏月夜背景、右侧浮动导航、场景旁白与对白、底部透明输入区 | 梦境氛围强；正式实现需额外验收暗色对比度 |
| D 生活卡片 | d-peach.html | 生活首页、会话入口大卡、双列花园与手帐、独立聊天页面 | 活泼有亲和力；不偏成熟冷静 |

## 搜索参考（2026-10-09）

- [Apple · Behind the Design: Headspace](https://developer.apple.com/news/?id=fkfnhq8u)：温暖插画与清楚导航。D 借鉴其亲和原则，自绘太阳与山丘，不复制品牌插画。
- [Day One](https://dayoneapp.com/)：以文字与生活记录为中心。A 借鉴安静的阅读层级；米白与书信排版是本次原创方向。
- [Calm](https://www.calm.com/app)：冥想与睡眠场景。C 将自然氛围转为原创月夜 SVG，非其界面复刻。
- [Owaves](https://owaves.com/)：日常节奏与健康规划。B 借鉴轻量日常陪伴的取向，不照搬圆盘交互。

以上为灵感来源，不表示这些产品采用本示范的全部颜色、布局或功能。所有 SVG、布局与示范文本均在本次编写；未下载第三方素材，系统字体，无外部资源依赖。

## 怎么挑

先选整体气质，再指定局部组合，例如「B 的聊天 + A 的日记 + C 的梦境」。重点看：长消息读起来是否舒服、输入区是否清楚、每天打开是否愿意停留。四套导航结构均为提案，正式接入时再决定是否保留原侧栏结构。

范围：纯 HTML/CSS/JS 视觉参考，无跨端影响。示例连接状态、日记、植物与设置均是假数据；设置可点击体验但不保存。能力检查只有只读状态。无真实权限、网络、通知、手机操作。Flutter/Android 接入、真机键盘与性能验收均 not-run。

# 聊天情况（2026-09-12）

入口：侧边栏 → 养成 → 聊天情况，位于状态花园上方。日／周／月／年视图均使用后端自然日统计，点击色块打开当天详情。年视图为十二个月日历；下拉或刷新按钮重新读取。

`ConversationCalendarController` 独立持有查询、选中日期、连续天数与请求 generation；页面负责创建和销毁，组合根仅传入连接、显示名和本机配色。不添加 Timer、业务台账或统计缓存。

HTTP：`GET /chat-log/stats/calendar`，复用 `BackendClient` 的 origin 校验、Bearer、超时和错误处理，要求 `memory.read` + `state.read`。周期请求使用 period/date；后续当日和连续天数查询固定首次响应的 char_id，避免后台切换角色导致混算。迟到响应不会覆盖新查询，离开页面后不更新已销毁控制器。

日期以服务器为准，默认查询不发送客户端今天。连续天数从服务器今天开始（今天为零时从昨天开始），回看最多 366 天；只累计实际已知且大于零的聊天轮数。到未知历史边界或查询上限时显示 `≥`，没有证据时不虚构连续天数。tracking_since 不参与陪伴时长推算。

统计展示：null 使用 `—`，未来日期不可点击；totals 重新按已知日值汇总，全部未知仍显示 `—`。partial/unavailable 和 usage 缺失保留说明。现实聊天按一问一答；工具含失败尝试；图片是模型视觉/OCR 提交张次；Token 可含后台和 Dream，不称完整账单。

配色入口：设置 → 外观与显示 → 聊天情况配色。苔绿／雾蓝／蔷薇／暖杏作用于统计卡片、热力图和指标，沿用日夜基础面板色。本机 YxPrefs.calendarPalette 经既有 getAppearancePrefs/setAppearancePrefs 保存（默认 jade），不成为后端功能开关。Dart store/channel 注释和 Android MainActivity 同步维护。

三面闭环：管理面沿用后端只读统计观测，无需新增业务设置、默认值、审计或 effective state；桌面保留独立客户端接入计划，不修改其实现。该页只读，无新权限、上传、队列、关联键、去重、ack、TTL、后台服务或通知变化，原 mobile chat/poll 与生活记录同步链不变。后端三仓总账中的 mobile UI roadmap 已由本仓实现推进，真实后端/设备联调仍属 observe；本轮未修改相邻仓库。

同批设置整理：侧栏移除角色资料入口，设置新增与系统配置／外观同级的角色资料折叠卡片。首项为紧凑头像、名称与编辑动作；原外观资料入口、备注名/默认头像重复行和开发说明删除，保留当前状态与后端角色切换。

对比度：生活记录校正弹窗与输入框不再继承根亮色 Theme 的背景，标题、正文、标签、选区随当前配色；主聊天“现在”标签使用顶栏 characterOn 前景与边框。
